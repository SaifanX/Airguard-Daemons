## 2025-02-28 - [CRITICAL] Prevent API Key Exposure & Confused Deputy Vulnerability
**Vulnerability:** The Gemini API key (`process.env.API_KEY`) was injected directly into the public client bundle via `vite.config.ts`'s `define` property. Furthermore, the `AiAssistant.tsx` client constructed its own system instructions to send directly to the Google GenAI API or passed them directly to a backend action, making it susceptible to prompt injection (Confused Deputy).
**Learning:** For frameworks using Vite, never use `define` or `import.meta.env` for server-side secrets. Convex actions must handle secret resolution on the backend. When implementing LLM integrations, system instructions must be strictly formulated on the server-side to prevent malicious clients from hijacking the AI prompt.
**Prevention:** Remove API key injection from `vite.config.ts`. Migrate the AI API call entirely to a Convex backend action (`askCaptain`). The client must only send contextual strings (like `weatherContext`, `zoneContext`) instead of formulating system instructions.
