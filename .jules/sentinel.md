## 2026-06-11 - [CRITICAL] API Key Exfiltration in Vite Config
**Vulnerability:** The `vite.config.ts` file used the `define` property to expose `process.env.GEMINI_API_KEY` explicitly to the client bundle (`'process.env.GEMINI_API_KEY': JSON.stringify(env.GEMINI_API_KEY)`). This is a severe security risk as it exposes the server-side AI API key directly to the public in plain text.
**Learning:** Any variable passed into the Vite `define` object is stringified and embedded natively into the front-end code, bypassing Vite's `VITE_` prefix protections. This provides direct access for any user inspecting the bundle to steal the backend API key.
**Prevention:** Never use the `define` object in Vite configurations for secrets. Move sensitive logic like AI generation completely to the backend, utilizing actions running on Node isolates (with `"use node";` in Convex). The frontend should strictly transmit necessary telemetry and context for the server to run the AI completions.
