## 2025-02-14 - Fix Client-Side API Key Exposure and Prompt Injection
**Vulnerability:** Found `GEMINI_API_KEY` explicitly exposed in `vite.config.ts` via the `define` property, bleeding the key to the frontend bundle. Additionally, AI system instructions were constructed on the client-side (`services/geminiService.ts`) and sent directly to the model, leading to Confused Deputy / Prompt Injection vulnerabilities.
**Learning:** Vite's `define` configuration completely bypasses the `VITE_` prefix protections, leaking any secrets defined within it to the frontend bundle in plain text. AI context and system prompts must always be constructed securely on the backend action.
**Prevention:** Never use `define` in Vite configurations for any sensitive keys. Initialize AI actions on the frontend using `useAction` and pass the action reference to utility functions. Format contextual data (like `weatherContext`) on the frontend, but hardcode system prompts explicitly on the backend action (e.g., in `convex/ai.ts`).
