## 2026-05-29 - Fixed Critical AI Key Exposure Vulnerability
**Vulnerability:** The `VITE_` or equivalent API keys required for AI modules (`GEMINI_API_KEY`) were being explicitly leaked into the client side application code using Vite's `define` property. Further, the Gemini model was running inside the client component `services/geminiService.ts` providing full prompt injection vectors and key leaks.
**Learning:** `define` strings are evaluated at build time and replaced globally in source mapping, overriding all standard `import.meta.env` prefix protections and exposing the exact literal keys. Client-side interaction with generative AI components also inherently lacks security due to uncontrolled prompt contexts and exposed API instances.
**Prevention:** Keys should be accessed uniquely inside Convex backend functions running under the node runtime using `"use node"`. Context and parameters should be safely formatted into read-only strings locally on the frontend before being sent as strictly validated args using `v.string()` schemas via the generic Convex remote action.
