## 2025-05-23 - Prevent API Key Client-Side Injection (Confused Deputy)
**Vulnerability:** The Google Gemini `API_KEY` was being inadvertently bundled and exposed to the client-side frontend using `define` in `vite.config.ts`. Additionally, the frontend was running the GenAI SDK directly, allowing malicious users to arbitrarily control the prompt and extract the raw API key from the bundle.
**Learning:** `vite.config.ts`'s `define` exposes environment variables entirely bypasses rules like `VITE_` prefixing if explicitly requested. Running Node modules specifically handling API requests (like `@google/genai`) on the V8 isolate edge runtime without `"use node";` also risks module failures.
**Prevention:** Remove sensitive secrets from Vite's `define`. Move all AI model invocations to a secure backend action (e.g., via Convex with `"use node";`), accept raw contextual variables, and build the full system prompt exclusively on the backend to avoid prompt injection vulnerabilities.
