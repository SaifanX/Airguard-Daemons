## 2025-05-27 - Hardcoded API Key Exposure in vite.config.ts\n**Vulnerability:** The `vite.config.ts` file exposes the `GEMINI_API_KEY` to the client-side bundle via the `define` configuration. This allows anyone using the application to extract the API key and misuse it.\n**Learning:** Vite`s `define` property injects the specified value as a plain string into the bundled code. Sensitive keys must not be passed this way.\n**Prevention:** API keys should only be accessible on the server. The application already uses a backend (`convex/ai.ts` handling `askCaptain`), so the frontend should not require the API key. Remove the `define` injection from Vite configuration.
