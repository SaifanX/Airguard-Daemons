## 2026-05-14 - Critical API Key Exposure via Vite Define
**Vulnerability:** The `GEMINI_API_KEY` was being injected into the client bundle via Vite's `define` configuration and accessed directly in the frontend `services/geminiService.ts`. This allowed anyone to extract the key from the compiled JavaScript. Additionally, the backend convex action `askCaptain` suffered from a Confused Deputy vulnerability where the entire system instruction could be overridden by the client.
**Learning:** Never use `define` or `import.meta.env` to expose sensitive secrets to the client. All AI interactions must be proxied through secure backend actions. The backend must exclusively construct the security-critical system prompt, accepting only sanitized contextual data from the client to prevent prompt injection.
**Prevention:** Remove secret keys from `vite.config.ts`. Ensure Convex actions handling AI interactions use the `"use node";` directive for Node modules and securely construct the prompt server-side using `process.env`.
