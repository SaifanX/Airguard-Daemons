## 2026-05-15 - [CRITICAL] Prevented Gemini API Key Injection in Vite bundle
**Vulnerability:** The Gemini API key (`process.env.API_KEY` and `process.env.GEMINI_API_KEY`) was injected directly into the frontend bundle using Vite's `define` configuration (`vite.config.ts`), exposing it to anyone viewing the source of the page.
**Learning:** Build tools like Vite with the `define` capability or `VITE_` prefix environment variables can easily leak sensitive keys into public client-side builds. Even if the AI integration requires heavy context construction on the frontend (like calculating intersections with turf.js), the actual generation function interacting with the GenAI SDK must always remain strictly server-side.
**Prevention:** Never use `define` in `vite.config.ts` for sensitive keys. Keep the AI system prompt construction and `@google/genai` library isolated to a backend Convex action, and pass only context string arguments from the client bundle to the backend. Ensure `process.env.API_KEY` is loaded directly by the server function.
